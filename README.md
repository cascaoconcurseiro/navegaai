# NavegaAI Cognitive Runtime — desenvolvimento

**Status:** branch de engenharia em avaliação; não há paridade comprovada com Claude. Esta branch incorpora fronteira de confiança para o conteúdo das páginas, análise estruturada de risco, autorização vinculada ao alvo, visão opcional no Playwright e verificações conservadoras de resultados externos.

Veja [os critérios de qualidade e limitações](docs/COGNITIVE-RUNTIME-V4-RELEASE-GATES.md). O motor preserva a base funcional da versão 3.3 RC2.
